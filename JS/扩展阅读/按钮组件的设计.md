## 组件库设计

- **现代封装库（Element Plus / AntD / Vant 等）**：在组件内部已经帮你把默认原生属性设成了 `type="button"`。把 `<el-button>` 放进 `<form>` 里直接点击，**不会**触发意外的表单提交；只有当你明确想用它提交原生表单时，才需要手动加上 `native-type="submit"` 或 `html-type="submit"`。
    
- **Headless / 样式透传库（shadcn/ui、Radix UI 等）**：这类组件直接渲染原生 `<button>` 并透传属性，很多默认还是原生行为（`submit`），放在表单里时依然需要显式写上 `type="button"`。

> **shadcn/ui** 的本质是**把带 Tailwind 样式的原生 HTML 标签复制进你的项目**。它的设计哲学是：除了视觉样式（`variant`、`size`）和插槽组合（`asChild`）之外，组件的 DOM 行为必须和原生 `<button>` 100% 一致，不引入任何“隐藏魔法”。
