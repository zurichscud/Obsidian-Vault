02

选择类 choice controls

复选框允许零个、一个或多个选项；单选按钮在同一 name 下只能选中一个。

CHOICE · 2 TYPES
checkbox 复选框

允许从多个选项中选择零个、一个或多个。

已选 已选 1 项 · 阅读

每个选项独立勾选；点击文字同样可以切换。

radio 单选按钮

同一 name 属性下的多个选项只能选中一个。

当前 邮件

点击文字即可选中；同一组内切换时，旧选项自动取消。

05

关键属性 attributes

除了 type，name、value、placeholder、autocomplete 与状态属性共同决定了控件如何被使用、如何被提交。

ATTRS · 交互与状态
name / value 标识与数据

name 是提交时的键名；没有 name 的字段在原生表单提交时会被忽略。

name="username"
会被忽略
尚未读取

value 是控件的当前值；对于 radio 和 checkbox，代表选中后提交的值。

disabled / readonly 状态控制

两个字段外观相似，但一个不可提交，另一个会照常提交。

禁用
只读
尚未读取
disabled不可点击、不可聚焦，不会随表单提交。
readonly不可修改，但可聚焦、选中复制，且会随表单提交。

placeholder

输入后消失

提供占位符提示文本，用户输入后自动消失。

autocomplete

autocomplete="email"

控制浏览器的自动填充行为，如 off、on、new-password。

autofocus

<input type="text" autofocus />

页面加载完成后自动获取焦点，无需用户先点击。

07

最佳实践 in practice

label、input / change 事件、中文输入法合成与 inputmode，是原生输入控件落地时的四个实践细节。

PRACTICE · 4 NOTES
3.1

务必搭配 label

通过 for 绑定 id，或直接用 label 包裹 input。

点击文字任意位置 未勾选
label[for] 
<label for="agree">
  <input type="checkbox" id="agree" name="agree" />
  我已阅读并同意协议
</label>

这不仅对屏幕阅读器至关重要，还能扩大点击区域——尤其是单选框和复选框，点击文字即可选中。

3.2

input 与 change

文本框 change 在失焦后触发；radio、checkbox、file 则在状态改变时立即触发。

input 实时 / change 失焦

文本框输入后，点击卡片外的空白处让输入框失焦，才会看到 change。

EVENT STREAM 0 input0 change

开始输入，事件会实时出现在这里。

前端框架的双向绑定（如 v-model）底层本质上就是监听 input（或 change）事件并动态更新 value（或 checked）。

3.3

中文输入法（IME）合成问题

拼音阶段的 input 也会触发；等选词上屏再处理时，配合 compositionstart / compositionend。

试试输入「输入法」
等待输入 composition —

中文输入时观察 composition 事件。

监听 input 做实时搜索时，拼音“敲拼音但未选词上屏”阶段也会触发 input；需要等选词确认再处理，则配合 compositionstart 和 compositionend。

3.4

移动端键盘优化 inputmode

输入纯数字验证码时，text + inputmode 保留文本特性，同时弹出数字键盘。

type="number"
value = "0123"
type="text" + inputmode="numeric"
value = "0123"
手机端打开观察键盘 
<input type="text" inputmode="numeric" />

type="number" 会带上下箭头，并忽略前导零如 0123；改用 text + inputmode="numeric"，既能保持文本特性，又能让手机弹出纯数字键盘。
