## 1. 防抖与节流

防抖（debounce）和节流（throttle）都是用来**限制函数执行频率**的技术，针对 `scroll`、`resize`、`input`、`mousemove` 这类**短时间内会触发几十上百次**的高频事件。如果每次触发都执行处理函数，会浪费性能，甚至让页面卡顿，或者发出大量无用的请求。

两者的区别在于“怎么限制”：

- **防抖**：事件连续触发时不执行，**等停下来一段时间后，才执行一次**。
- **节流**：事件连续触发时，**每隔固定时间最多执行一次**。

## 2. 防抖(等你停下来)

### 2.1 基础用法：搜索框

下面的示例把搜索处理函数包成防抖函数，再绑定到 `input` 事件上：

```js
const onSearch = debounce((keyword) => {
  console.log('发请求：', keyword);
}, 500);

input.addEventListener('input', (e) => onSearch(e.target.value));
```

用户停止输入 500ms 后，才会执行一次。

### 2.2 配置项

`debounce` 的第三个参数用来配置执行时机，包含以下三个选项：

```js
debounce(fn, 500, {
  leading: false,   // 默认 false：是否在开始时立即执行
  trailing: true,   // 默认 true：是否在停止后执行
  maxWait: 2000,    // 最长等待时间，超过就强制执行一次
});
```

### 2.3 场景示例

#### 场景 1：防止按钮连点（第一次立即执行，之后忽略）

下面的示例打开 `leading`、关闭 `trailing`，只在第一次点击时执行：

```js
const onSubmit = debounce(submitForm, 1000, {
  leading: true,
  trailing: false,
});
button.addEventListener('click', onSubmit);
```

#### 场景 2：自动保存（持续输入时也要定期保存）

下面的示例给自动保存加上 `maxWait`：

```js
const autoSave = debounce(save, 1000, { maxWait: 5000 });
editor.addEventListener('input', autoSave);
```

普通防抖在用户一直输入时永远不会触发保存；加了 `maxWait`，最多 5 秒就会强制保存一次。

## 3. 节流

### 3.1 基础用法：滚动

下面的示例把滚动处理函数包成节流函数：

```js
const onScroll = throttle(() => {
  console.log('滚动位置：', window.scrollY);
}, 200);

window.addEventListener('scroll', onScroll);
```

滚动过程中，每 200ms 最多执行一次。

### 3.2 配置项

`throttle` 的第三个参数同样用来配置执行时机，包含以下两个选项：

```js
throttle(fn, 200, {
  leading: true,   // 默认 true：开始时立即执行一次
  trailing: true,  // 默认 true：结束后补一次最后的调用
});
```

### 3.3 场景示例

按钮点击限流，一秒内只响应一次

下面的示例关闭 `trailing`，一秒内只响应一次点击：

```js
const onClick = throttle(doSomething, 1000, { trailing: false });
button.addEventListener('click', onClick);
```
