**BOM（Browser Object Model，浏览器对象模型）** 是指浏览器提供的一系列用于与浏览器窗口进行交互的对象集合。

## 1. 核心层级结构

BOM 缺乏官方的 W3C 统一标准，但现代浏览器基本都遵循同一套事实标准。它的核心是 **`window`** 对象，所有其他 BOM 对象都是 `window` 的属性：

- **`window`（顶层对象）**：代表整个浏览器窗口。在浏览器环境中，它同时也是 JS 的**全局对象**（即 `globalThis`），所有全局变量和函数都会挂载在 `window` 上。
- **`location`（地址栏对象）**：用于获取或修改当前页面的 URL，实现页面跳转或刷新。
- **`history`（历史记录对象）**：操作浏览器的前进、后退历史栈（单页应用路由的底层基石之一）。
- **`navigator`（浏览器信息对象）**：包含浏览器名称、版本、操作系统、网络状态、剪贴板、地理位置等环境信息。
- **`screen`（屏幕对象）**：获取用户物理显示器的分辨率、可用宽高、色彩深度等信息。
- **`document`（文档对象）**：即 DOM 的根节点，它同时也是 `window` 的一个子属性（`window.document`）。
