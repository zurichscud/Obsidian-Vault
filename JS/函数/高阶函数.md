---
title: 高阶函数
description: 操作函数的函数
---

**高阶函数** 指满足以下至少一个条件的函数：

1. **接收一个或多个函数作为参数**
    
2. **返回一个函数**

## 1. 函数作为参数

把 `sayHello` 作为参数传入 `execute`：

```js
function sayHello(name) {
  console.log(`Hello ${name}`);
}

function execute(fn, value) {
  fn(value);
}

execute(sayHello, 'Tom');
```

## 2. 函数作为返回值

`createMultiplier` 接收 `x`，返回一个新函数：

```js
function createMultiplier(x) {
  return function (y) {
    return x * y;
  };
}

const double = createMultiplier(2);

console.log(double(5));
```

## 3. 高阶函数的意义

### 3.1 代码复用

给任何函数增加日志功能：

```js
function withLog(fn) {
  return function () {
    console.log('执行前');
    fn();
    console.log('执行后');
  };
}
```

### 3.2 函数增强

不用修改 `oldFn`，直接增强它：

```js
const newFn = withLog(oldFn);
```

**逻辑抽象与复用**：将通用的控制流程（循环、异常处理、防抖）与具体的业务逻辑拆分开。
