title: 函数柯里化
---

## 1. 定义

**函数柯里化（Currying）** 是一种将接收多个参数的函数，转换为一系列只接收单个参数（或部分参数）且返回新函数的技术。

核心思想：**将多参调用 `f(a, b, c)` 转换为连续单参调用 `f(a)(b)(c)`**。

> 柯里化本质上就是高阶函数的一种应用（接收参数并返回新函数）。

```js
// 普通函数
const add = (a, b, c) => a + b + c;
add(1, 2, 3); // 6

// 柯里化后
const curriedAdd = a => b => c => a + b + c;
curriedAdd(1)(2)(3); // 6
```

## 3. 为什么要使用柯里化

### 3.1 参数复用（偏函数 / 预置参数）

先固定部分参数，生成更专用的函数。

不使用柯里化时，需要为每种校验单独定义函数：

```js
function checkPhone(text) {
  return /^1\d{10}$/.test(text);
}

function checkEmail(text) {
  return /^[\w.-]+@[\w.-]+\.\w+$/.test(text);
}

checkPhone('13800000000'); // true
checkPhone('12345');       // false
```

使用柯里化后，可以用同一个 `check` 生成校验函数：

```js
// 正则匹配工具
const check = reg => text => reg.test(text);

const checkPhone = check(/^1\d{10}$/);
const checkEmail = check(/^[\w.-]+@[\w.-]+\.\w+$/);

checkPhone('13800000000'); // true
checkPhone('12345');       // false
```

### 3.2 延迟执行

参数凑齐之前不会真正执行。

### 3.3 函数组合

单参数函数更容易配合 `map`、`filter`、`compose` 使用。

用柯里化后的 `multiply` 配合 `map`，对数组逐项计算：

```js
const multiply = a => b => a * b;
[1, 2, 3].map(multiply(10)); // [10, 20, 30]
```
