JavaScript 中参数处理的核心机制、进阶技巧与常见陷阱。

## 1. 默认参数（Default Parameters）

ES6 允许为形参指定默认值。当未传参或传入 `undefined` 时，默认值生效。

下面示例为 `role` 与 `status` 指定默认值，并对比不同实参传入时的结果。

```javascript
// 基础用法
function createUser(name, role = 'guest', status = 'active') {
  return { name, role, status };
}

createUser('Alice'); // { name: 'Alice', role: 'guest', status: 'active' }

// 触发条件：只有 undefined 会触发默认值，null 或空字符串不会
createUser('Bob', undefined, null); 
// => role 为 'guest'，status 为 null
```

## 2. 剩余参数（Rest Parameters）

使用 `...args` 将不确定数量的连续实参收集为一个**真正的数组**。

下面示例把 `multiplier` 之后的实参收集为 `numbers`，求和后再乘以 `multiplier`。

```javascript
// 收集末尾的所有额外参数
function sum(multiplier, ...numbers) {
  // numbers 是一个标准 Array 实例，可以直接调用 map、reduce 等方法
  return numbers.reduce((total, num) => total + num, 0) * multiplier;
}

sum(2, 1, 2, 3); // (1 + 2 + 3) * 2 = 12
```

使用剩余参数时，约束如下：

1. **只能有一个剩余参数**。
2. **必须放在形参列表的末尾**。

## 3. 参数解构（Destructuring Parameters）

结合解构赋值与默认值，常用于处理多配置项，避免“长参数列表”带来的维护问题。

### 3.1 对象解构

这里表示函数接收一个对象，并从中提取 `type`、`width`、`height` 三个属性。

```js
function createShape({ type, width, height }) {
}
```

### 3.2 属性默认值

这里给解构出来的属性设置了默认值。

```js
function createShape({
  type = 'rectangle',
  width = 100,
  height = 50
}) {
}
```

### 3.3 双重默认值

下面示例同时为解构属性与整个 `options` 对象赋予默认值。

```javascript
// 同时给解构属性与整个 options 对象赋予默认值
function request(url, {
  method = 'GET',
  headers = {},
  timeout = 5000,
} = {}) { //未传参时是空对象
  return { url, method, headers, timeout };
}

request('/api/users'); // 正常执行，使用所有默认值
request('/api/login', { method: 'POST' });
```

这里的 `= {}` 是函数参数的默认值，它解决的是：调用函数时完全不传参数的问题。

### 3.4 解构重命名与剩余参数

下面示例把 `name` 解构重命名为 `userName`，并将剩余未被显式解构的属性收集到 `extraMetadata`。

```javascript
function renderUser({ id, name: userName, role = 'member', ...extraMetadata }) {
  console.log(id, userName, role);
  console.log(extraMetadata); // 剩余未被显式解构的属性组成新对象
}
```

## 4. 展开运算符作为实参

Rest 是“收敛”（将分散参数合为数组），Spread 是“发散”（将数组或可迭代对象解开为独立实参）。

下面示例用展开运算符把数组元素作为独立实参传入。

```javascript
const coords = [12.5, 45.8, 100.2];

// 代替传统的 Function.prototype.apply
Math.max(...coords); 

function setLocation(x, y, z) {
  return `Point(${x}, ${y}, ${z})`;
}
setLocation(...coords);
```

## 5. `arguments` 对象（旧特性）

在 ES5 及之前，JavaScript 使用类数组对象 `arguments` 获取动态参数。

### 5.1 与剩余参数的对比

下表从类型、箭头函数支持、涵盖范围和严格模式绑定四个方面对比两者。

|**特性**|**arguments 对象**|**剩余参数 (...rest)**|
|---|---|---|
|**类型**|类数组（`Array-like`），无数组原型方法|原生 `Array` 实例|
|**箭头函数支持**|**不支持**（使用时捕获外层作用域的 `arguments`）|**原生支持**|
|**涵盖范围**|包含传入的所有实参|仅包含未被显式命名的剩余实参|
|**严格模式绑定**|严格模式下形参与 `arguments` 解绑；非严格模式下存在联动关系|无联动副作用，遵循词法变量绑定|

### 5.2 遗留用法与转数组

下面示例对比遗留的 `arguments` 转数组写法，以及推荐的剩余参数写法。

```javascript
// 遗留用法与转数组
function legacySum() {
  // 需要手动借用 Array 原型方法或使用 Array.from
  const args = Array.prototype.slice.call(arguments);
  return args.reduce((acc, curr) => acc + curr, 0);
}

// 现代替代方案（推荐）
const modernSum = (...args) => args.reduce((acc, curr) => acc + curr, 0);
```

## 6. 传参机制：按值传递

JavaScript 的所有参数传递在底层**严格是按值传递**，区别在于传递的值是原始类型还是引用类型：

- **原始类型**：传递值的副本，函数内部重新赋值不影响外部。
- **引用类型**：传递的是**引用的地址副本**。修改对象属性会影响外部。

下面示例分别修改原始类型的副本、引用类型对象的属性，以及形参自身的引用，观察外部变量的变化。

```javascript
function mutate(primitive, obj) {
  primitive = 100;        // 仅修改局部副本
  obj.name = 'Updated';   // 修改指针指向的堆内存，外部可见
  obj = { name: 'New' };  // 仅改变局部变量引用，外部无感
}

let num = 10;
let user = { name: 'Initial' };

mutate(num, user);
console.log(num);       // 10
console.log(user.name); // "Updated"
```
