---
title: 纯函数
---

## 1. 纯函数的定义

如果一个函数满足以下两个条件，它就是纯函数：

1. **确定的输入产生确定的输出**：对于相同的输入参数，无论调用多少次、在什么环境下执行，函数返回的结果永远相同。
2. **无副作用**：函数在执行过程中，不会修改外部状态，也不会产生任何可被外界察觉的副作用。

## 2. 纯函数示例

下面这个函数只依赖传入的参数：

```js
function add(a, b) {
  return a + b;
}

add(1, 2); // 永远返回 3
add(1, 2); // 永远返回 3
```

结果只由 `a` 和 `b` 决定，因此它是纯函数。

箭头函数的写法同样满足条件：

```js
n=>n+1
```

相同的输入具有相同的输出，函数没有更改 `n` 的值，只是将 `n + 1` 返回了，因此是纯函数。

## 3. 非纯函数示例

下面的函数依赖外部变量 `count`：

```js
let count = 10;

function add(num) {
  return num + count;
}

add(5); // 15
```

函数依赖于外部 `count` 的状态。如果 `count` 更改为 20，对于相同的输入 `num`，输出不同，因此不是纯函数。
