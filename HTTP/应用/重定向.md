---
title: 重定向
---

常见重定向状态码如下：

| 状态码 | 含义 | 是否永久 |
| --- | ----- | ---- |
| 301 | 永久重定向 | 是 |
| 302 | 临时重定向 | 否 |

## 1. 302 临时重定向

Found（临时重定向）：请求的资源暂时被移动到了另一个 URL，客户端应该去新的地址请求。

浏览器请求：

```http
GET /login
Host: example.com
```

服务器返回 302 + Location 响应头，告诉浏览器跳转：

```http
HTTP/1.1 302 Found
Location: https://github.com/login/oauth/authorize
```

浏览器跳转到新的地址：

```
GET https://github.com/login/oauth/authorize
```

## 2. 301 永久重定向

Moved Permanently（永久重定向）：请求的资源已经永久移动到新的 URL，以后都应该使用新的地址。

浏览器请求：

```http
GET /old-page
Host: example.com
```

服务器返回：

```
HTTP/1.1 301 Moved Permanently
Location: https://example.com/new-page
```

浏览器请求新的地址：

```http
GET /new-page
Host: example.com
```

## 3. 301 的实际意义

> [!note]
> - SEO
> - 浏览器会长期缓存：后续用户访问旧的地址时，可能直接跳转，不必再次请求服务器。
