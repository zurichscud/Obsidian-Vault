
HTTP 缓存分为**私有缓存与共享缓存两大类，核心区别在于存储位置、服务对象以及数据安全边界**。

## 核心区别对比

| **维度**     | **私有缓存**                              | **共享缓存**                               |
| ---------- | ------------------------------------- | -------------------------------------- |
| **物理位置**   | 客户端本地（浏览器、App 内部）                     | 网络中间节点（CDN、反向代理）                       |
| **服务对象**   | 单一特定用户                                | 多个不同用户（公用复用）                           |
| **典型存储内容** | 个人隐私数据、用户中心资料、会话历史、订单状态               | 静态资源（JS/CSS/图片）、公共文档、公开商品详情            |
| **典型响应头**  | `Cache-Control: private, max-age=300` | `Cache-Control: public, s-maxage=3600` |

## 示例代码

```js
import express from 'express';
const app = express();

// 1. 私有缓存：仅当前浏览器存 5 分钟，禁止 CDN 存
app.get('/api/user', (req, res) => {
  res.set('Cache-Control', 'private, max-age=300').json({ name: 'Alice' });
});

// 2. 共享缓存：浏览器存 1 分钟，CDN（共享代理）存 1 小时
app.get('/api/public-list', (req, res) => {
  res.set('Cache-Control', 'public, max-age=60, s-maxage=3600').json(['A', 'B']);
});

// 3. 彻底不存：敏感数据
app.get('/api/pay', (req, res) => {
  res.set('Cache-Control', 'no-store').json({ status: 'ok' });
});

app.listen(3000);
```
