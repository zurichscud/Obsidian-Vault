在 Sequelize 中实现软删除主要通过 **`paranoid` 模式**来完成。

## 1. 启用软删除

在模型定义时添加 `paranoid: true` 选项即可：

```js
class Post extends Model {}

Post.init(
  {
    // 属性定义
  },
  {
    sequelize,
    paranoid: true,  // 启用软删除
    // 可选：自定义删除时间字段名
    deletedAt: 'destroyTime',
  }
);
```

**注意**：`paranoid` 模式依赖 `timestamps`，因此不能同时设置 `timestamps: false`。

## 2. 软删除数据

调用 `destroy` 方法时，不会真正删除记录，而是将 `deletedAt` 字段设置为当前时间戳：

```js
// 软删除
await Post.destroy({
  where: { id: 1 }
});
// 执行 SQL: UPDATE "posts" SET "deletedAt"=[timestamp] WHERE "deletedAt" IS NULL AND "id" = 1

// 实例方法同样适用
const post = await Post.create({ title: 'test' });
await post.destroy();  // 软删除
```

## 3. 硬删除（真正删除）

如果需要彻底删除记录，使用 `force: true` 选项：

```js
await Post.destroy({
  where: { id: 1 },
  force: true  // 强制硬删除
});
// 执行 SQL: DELETE FROM "posts" WHERE "id" = 1
```

## 4. 恢复软删除的记录

使用 `restore` 方法可以恢复被软删除的数据：

```js
// 实例恢复
const post = await Post.create({ title: 'test' });
await post.destroy();
await post.restore();  // 恢复

// 批量恢复
await Post.restore({
  where: {
    likes: { [Op.gt]: 100 }
  }
});
```

## 5. 查询包含已删除的记录

默认情况下，所有查询都会自动过滤掉软删除的记录。如需查询包含已删除的数据，添加 `paranoid: false`：

```js
// 只查询未删除的记录
await Post.findByPk(123);  // 如果已软删除，返回 null

// 查询包含已删除的记录
await Post.findByPk(123, { paranoid: false });

await Post.findAll({
  where: { foo: 'bar' },
  paranoid: false  // 同时检索软删除的记录
});
```
