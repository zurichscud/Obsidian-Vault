## 1. 错误处理中间件的签名

错误处理中间件有四个参数，Express 据此区分于普通中间件：

```js
app.use((err, req, res, next) => {
  console.error(err.stack);
  if (res.headersSent) return next(err);
  res.status(err.status || 500).json({ message: err.message || '服务器错误' });
});
```

要点：

- 必须注册在所有路由之后。
- 若响应头已发送（`res.headersSent` 为 true），把错误交给 Express 默认处理。
- Express 4 不会自动捕获异步错误：Promise rejection 或 async 函数抛错不会进入错误中间件，需手动 `try/catch` 后调用 `next(err)`。
- Express 5 会自动捕获 async 路由/中间件抛出的错误并转发给错误中间件。

## 2. 异步场景的写法（Express 4）

异步场景的写法（Express 4）如下，在 `catch` 中调用 `next(err)` 把错误交给错误处理中间件：

```js
app.get('/data', async (req, res, next) => {
  try {
    const data = await fetchData();
    res.json(data);
  } catch (err) {
    next(err);
  }
});
```

## 3. 404 处理

404 本质上是一个"未匹配到任何路由"的兜底中间件，注册在路由之后、错误处理之前：

```js
app.use((req, res) => {
  res.status(404).json({ message: 'Not Found' });
});
```
