## 1. 常用第三方中间件

第三方中间件通过 npm 安装，常见如下：

| 中间件 | 用途 |
|---|---|
| `cors` | 跨域资源共享 |
| `helmet` | 设置安全相关 HTTP 头 |
| `morgan` | HTTP 请求日志 |
| `cookie-parser` | 解析 Cookie |
| `compression` | 响应压缩（gzip） |
| `express-rate-limit` | 限流 |
| `multer` | 文件上传（multipart/form-data） |
| `express-validator` / `zod` | 请求校验 |

## 2. 使用示例

以下示例引入并注册 `helmet`、`cors`、`morgan` 三个中间件：

```js
const cors = require('cors');
const helmet = require('helmet');
const morgan = require('morgan');

app.use(helmet());
app.use(cors());
app.use(morgan('combined'));
```
