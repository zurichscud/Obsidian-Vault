## 1. 内置中间件概览

Express 内置的中间件，无需安装第三方包：

- `express.json()`：解析 JSON 请求体
- `express.urlencoded()`：解析 URL-encoded 请求体
- `express.static()`：托管静态资源
- `express.raw()` / `express.text()`：按原始字节或文本解析请求体

## 2. express.json()

解析 `Content-Type: application/json` 的请求体，挂到 `req.body`。支持大小限制：

```js
app.use(express.json({ limit: '32kb' }));
```

其作用包括：

1. **解析请求体**：把 `Content-Type: application/json` 的请求体解析成 JavaScript 对象，挂到 `req.body`，后续路由/控制器可以直接使用 `req.body`。
2. **大小限制**：`limit: '32kb'` 限制请求体最大 32KB。

## 3. express.urlencoded()

解析 `Content-Type: application/x-www-form-urlencoded` 的请求体：

```js
app.use(express.urlencoded({ extended: true }));
```

- `extended: true`：使用 `qs` 库，支持嵌套对象。
- `extended: false`：使用 `querystring`，仅支持扁平键值。

## 4. express.static()

以下代码注册 Express 的静态资源服务中间件，把 `public` 目录下的文件对外提供访问：

```js
app.use(express.static('public'));
```

其作用包括：

1. **托管静态文件**：把指定目录（如 `public`）下的文件按 URL 路径对外提供访问，例如 `public/index.html` 可通过 `/index.html` 访问，`public/css/style.css` 可通过 `/css/style.css` 访问。
2. **自动设置 Content-Type**：根据文件扩展名自动设置响应的 `Content-Type`。
3. **自动处理 404**：文件不存在时不会报错，而是调用 `next()` 交给后续中间件/路由处理。

挂载到指定前缀路径：

```js
app.use('/static', express.static('public'));
// 访问 /static/index.html 对应 public/index.html
```

常用选项：

```js
app.use(express.static('public', {
  maxAge: '1d',        // 设置 Cache-Control: max-age=86400
  etag: true,          // 生成 ETag
  lastModified: true,  // 设置 Last-Modified
  index: 'index.html', // 目录默认文件
  redirect: true,      // 目录请求自动重定向到带尾斜杠的 URL
}));
```

> [!warning] **避免暴露敏感文件**
> 只把需要公开的目录（如 `public`）作为静态根目录，不要把项目根目录或包含配置/密钥的目录对外暴露。

## 5. express.raw() / express.text()

以下代码分别注册原始字节解析与文本解析中间件：

```js
app.use(express.raw({ type: 'application/octet-stream', limit: '1mb' }));
app.use(express.text({ type: 'text/plain' }));
```
