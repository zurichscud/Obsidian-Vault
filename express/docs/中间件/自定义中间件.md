## 1. 日志中间件

以下代码记录请求方法、URL、状态码与耗时：

```js
function requestLogger(req, res, next) {
  const start = Date.now();
  res.on('finish', () => {
    console.log(`${req.method} ${req.originalUrl} ${res.statusCode} ${Date.now() - start}ms`);
  });
  next();
}
app.use(requestLogger);
```

## 2. 认证中间件

以下代码从 `Authorization` 头读取令牌，校验通过后把用户信息挂到 `req.user`，校验失败则把错误交给 `next(err)`：

```js
function authRequired(req, res, next) {
  const token = req.get('Authorization');
  if (!token) return res.status(401).json({ message: '未提供令牌' });
  try {
    req.user = verifyToken(token);
    next();
  } catch (err) {
    next(err);
  }
}

app.get('/profile', authRequired, (req, res) => {
  res.json(req.user);
});
```

## 3. 校验中间件

以下代码要求请求体中的 `username` 与 `password` 必填，缺失时返回 400：

```js
function validateUser(req, res, next) {
  const { username, password } = req.body || {};
  if (!username || !password) {
    return res.status(400).json({ message: 'username 和 password 必填' });
  }
  next();
}

app.post('/users', validateUser, createUser);
```

## 4. 在中间件间传递数据

- 请求级数据：挂到 `req`（如 `req.user`）或 `res.locals`。
- `res.locals` 适合模板渲染与当前请求内共享。

以下代码把开始时间写入 `res.locals.startTime`：

```js
app.use((req, res, next) => {
  res.locals.startTime = Date.now();
  next();
});
```
