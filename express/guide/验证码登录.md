验证码登录的完整流程如下：

```
用户输入手机号
|
v
请求发送验证码
|
v
验证码服务生成验证码
|
+----> 保存验证码(缓存)
|
+----> 调用短信平台发送
|
v
用户输入验证码
|
v
后端校验验证码
|
v
查询/创建用户
|
v
生成登录凭证(Token)
|
v
返回前端
```

## 1. 发送验证码接口

发送验证码接口的请求如下：

```http
POST /auth/send-code

{
"phone": "13800138000"
}
```

### 1.1 限制频率

在 Redis 记录发送验证码的手机号，并设置有效期，防止短信轰炸。记录结构如下：

```
Key Value TTL
------------------------------------------------
sms:limit:13800138000 1 60秒
```

### 1.2 生成验证码

生成 6 位随机数字验证码：

```java
String code = RandomUtil.randomNumbers(6);
```

### 1.3 保存验证码

验证码一般存储于 Redis，并设置有效期：

```
Key Value TTL
------------------------------------------------
sms:login:13800138000 392841 300
```

### 1.4 发送短信

短信平台例如：

- 阿里云短信
- 腾讯云短信

短信内容模板如下：

```text
【公司名】您的验证码是392841，5分钟内有效。
```

## 2. 验证验证码接口

验证验证码接口的请求如下：

```http
POST /auth/login/code

{
"phone": "13800138000",
"code": "392841"
}
```

### 2.1 查询 Redis

从 Redis 取出该手机号对应的验证码：

```java
String realCode =
redis.get("sms:login:" + phone);
```

### 2.2 比较验证码

比较两者，不一致时抛出异常：

```java
if (!code.equals(realCode)) {
throw new Exception("验证码错误");
}
```

### 2.3 删除验证码

验证成功后，删除 Redis 中的验证码，防止重复使用：

```java
redis.delete("sms:login:" + phone);
```

### 2.4 用户处理

用户处理有两种方案。

#### 方案一：必须先注册

必须先注册时，流程如下：

```
手机号
|
查询用户
|
不存在
|
提示注册
```

#### 方案二：自动注册（现在更常见）

自动注册时，流程如下：

```
手机号
|
查询用户
|
不存在
|
创建用户
```

### 2.5 登录成功返回 Token

创建 Token 返回前端即可。
