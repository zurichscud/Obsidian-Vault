Zod 不仅能做校验，还能直接在校验流程中对数据做清洗，**执行顺序是从左到右**。

## 1. 变换与清洗

下面的示例依次去除首尾空格、转为小写，再对清洗后的结果做邮箱校验：

```typescript
const sanitizedInput = z
  .string()
  .trim()          // 自动去除首尾空格
  .toLowerCase()   // 自动转小写
  .email();        // 针对清洗后的结果进行邮箱校验

// 示例：
sanitizedInput.parse("  Admin@Domain.COM  ");
// 解析结果输出为: "admin@domain.com"
```

> **注意顺序**：建议将 `.trim()`、`.toLowerCase()` 放在 `.email()` 或 `.min()` **之前**，否则空格会参与长度计算，甚至导致邮箱正则匹配失败。

## 2. 强制类型转换

`z.coerce` 是 Zod 提供的**类型强制转换功能**。它会先尝试将输入转换为指定类型，再执行相应的校验规则。

下面的示例展示 `z.coerce.number()` 对不同输入的转换结果：

```typescript
import { z } from "zod";

const NumberSchema = z.coerce.number();

NumberSchema.parse("123"); // 123
NumberSchema.parse(123);   // 123
NumberSchema.parse(true);  // 1
NumberSchema.parse(null);  // 0
```

下表列出各 `z.coerce` 方法对应的底层转换逻辑：

| 方法 | 底层转换逻辑 | 示例 |
| --- | --- | --- |
| `z.coerce.string()` | `String(input)` | `123` → `"123"` |
| `z.coerce.number()` | `Number(input)` | `"123"` → `123` |
| `z.coerce.boolean()` | `Boolean(input)` | `"hello"` → `true` |
| `z.coerce.bigint()` | `BigInt(input)` | `"123"` → `123n` |

例如，下面的 Schema 在强制转换后限制数字范围：

```js
const Schema = z.coerce.number().min(0).max(10);
```

如果是字符串则强制转为数字，数字的范围是 0~10。

## 3. 数据预处理

`z.preprocess()` 用于在执行 Schema 校验之前，先对输入数据进行预处理（转换）。

### 3.1 参数与返回值

`z.preprocess` 接收两个参数：

1. **预处理函数 (`arg => processedArg`)**：接收最原始的未知输入，返回处理后的值。
2. **目标 Schema (`schema`)**：对处理后的值执行标准的 Zod 验证和类型推断。

返回值：Schema。

### 3.2 示例

下面的示例先用预处理函数去除字符串首尾空格，再用 `z.string().min(1)` 校验：

```js
import { z } from 'zod'

const schema = z.preprocess(
  (value) => {
    if (typeof value === 'string') {
      return value.trim()
    }
    return value
  },
  z.string().min(1)
)

schema.parse('  hello  ')
// 'hello'
```
