Zod 最常用的两个方法是 `parse()` 和 `safeParse()`。`parse` 可以理解为 **“解析”**

## 1. parse

> 校验失败时抛出异常

```javascript
import { z } from "zod";

const AgeSchema = z.number().min(18);

const age = AgeSchema.parse(20);

console.log(age); // 20
```

如果传入不符合要求的数据：

```javascript
AgeSchema.parse(15);
```

Zod 会抛出 `ZodError`。

因此，如果使用 `parse()`，可以通过 `try...catch` 处理异常：

```javascript
try {
  const age = AgeSchema.parse(15);

  console.log(age);
} catch (error) {
  console.error(error);
}
```

适合你希望校验失败直接进入异常处理流程的场景。

## 2. safeParse

> 校验失败时返回错误信息

```javascript
const result = AgeSchema.safeParse(15);
```

它不会因为普通的校验失败而抛出 `ZodError`，而是返回一个结果对象。

- 校验成功

```javascript
{
  success: true,
  data: 15
}
```

- 校验失败

```javascript
{
  success: false,
  error: ZodError
}
```

- 实际使用

```javascript
const result = AgeSchema.safeParse(15);

if (result.success) {
  console.log(result.data);
} else {
  console.log(result.error.issues);
}
```


## 3.严格模式

默认情况下，Zod 的 `z.object()` **会剔除 Schema 中没有定义的字段**。

```js
import { z } from "zod";

const RegisterSchema = z.object({
  username: z.string(),
  age: z.number().positive(),
});

const result = RegisterSchema.parse({
  username: "zhangsan",
  age: 18,
  password: "123456",
});

console.log(result);
```

输出：

```js
{
  username: "zhangsan",
  age: 18
}
```

注意：**`password` 不会导致校验失败，而是直接被剔除。**

如果想禁止额外字段，使用 `.strict()`：

```js
const RegisterSchema = z.object({
  username: z.string(),
  age: z.number().positive(),
}).strict();
```

此时传入 `password` 就会校验失败，因为 Schema 没有定义这个字段。
