
用 `tabs` 代码块创建页签，每个页签以 `=== 标题` 开头。

## 1. 基本用法

```tabs
=== 第一个页签
这里可以用 **Markdown**，也可以用 [[双链]]。

- 列表项
- 第二个列表项

| 列 A | 列 B |
| --- | --- |
| 1 | 2 |

=== 第二个页签
切到哪个页签，就只显示哪个页签的内容。

> 引用、公式、Callout 都能正常渲染。

=== 第三个页签

1. 有序列表
2. 第二项
```

## 2. 页签内嵌套代码块

外层围栏要用 4 个反引号，否则内层的三个反引号会提前结束代码块。

````tabs
=== 代码页签
```js
console.log("嵌套代码块也可以");
```

=== 表格页签
| 名称 | 说明 |
| --- | --- |
| tabs | 页签块 |
| === | 页签分隔符 |
````

## 3. QA 块

同样的 `=== 标题` 结构，换成 `qa` 语言就是可折叠的问答块：

```qa
=== 问题1
答案

=== 问题2
答案里同样可以用 **Markdown**、[[双链]] 和列表：

1. 第一条
2. 第二条
```

## 4. 没有分隔符时

块内不写 `===` 时，整块按普通 Markdown 渲染，不会生成页签栏：

```tabs
只有一段普通内容，因此这里不会出现页签栏。
```
