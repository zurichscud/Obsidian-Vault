PM2 是一个用于 Node.js 应用程序的生产级进程管理器（Process Manager），内置负载均衡、守护进程管理、性能监控以及零停机重载等功能。

## 1. 核心特性

- **后台持久运行**：程序崩溃自动重启，并支持开机自启。
- **集群模式（Cluster Mode）**：利用 Node.js 原生 Cluster 模块，无需修改业务代码即可实现多核 CPU 负载均衡。
- **零停机重载**：更新代码时支持平滑滚动更新，服务不中断。
- **日志集中管理**：自动合并或拆分标准输出与错误输出，支持日志轮转插件。
- **监控与资源限制**：实时查看 CPU/内存占用，并支持内存泄漏自动重启阈值配置。

## 2. 基础安装

### 2.1 全局安装

全局安装 PM2：

```bash
npm install -g pm2
# 或使用 pnpm
pnpm add -g pm2
```


### 运行项目

启动项目：

```
pm2 start app.js
```

启动 TypeScript 编译后的 Express 项目：

```
pm2 start dist/index.js --name api
```


-  `-i 8` 表示启动 8 个实例。它们共同监听同一个端口，由 PM2 负责负载均衡。
- `--name`为实例命名

### 2.2 常用命令

| **操作**    | **命令**                                          | **说明**               |
| --------- | ----------------------------------------------- | -------------------- |
| **启动服务**  | `pm2 start app.js --name "my-app"`              | 启动单实例并命名             |
| **集群启动**  | `pm2 start app.js -i max --name "api"`          | 启动并占用所有 CPU 核心（集群模式） |
| **状态查看**  | `pm2 list` / `pm2 ls`                           | 查看所有进程状态、CPU、内存及重启次数 |
| **实时监控**  | `pm2 monit`                                     | 终端仪表盘，监控系统资源与日志      |
| **日志查看**  | `pm2 logs [name\|id] --lines 50`                | 实时查看日志（默认输出最后 15 行）  |
| **平滑重载**  | `pm2 reload [name\|id]`                         | 零停机平滑更新（推荐生产环境使用）    |
| **重启进程**  | `pm2 restart [name\|id]`                        | 终止后重新拉起进程（会有瞬时中断）    |
| **停止/删除** | `pm2 stop [name\|id]` / `pm2 delete [name\|id]` | 停止进程或从列表中彻底移除        |
| **开机自启**  | `pm2 startup` 然后 `pm2 save`                     | 生成开机脚本并保存当前进程清单      |
