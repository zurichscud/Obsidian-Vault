## 1. 编写自动备份脚本

创建脚本文件 `/data/scripts/backup_db_to_oss.sh`。

## 2. 配置定时任务（Crontab）

通过 Linux 自带的 `crontab` 设定每日凌晨自动执行：

在末尾添加一行（例如每天凌晨 04:30 执行，并将日志保存至 `/var/log/db_backup.log`）：

```
30 4 * * * /data/scripts/backup_db_to_oss.sh >> /var/log/db_backup.log 2>&1
```

## 3. 保留周期管理

不需要在脚本里编写历史备份的自动删除逻辑。直接进入 **阿里云 OSS 控制台 -> 对应 Bucket -> 数据管理 -> 生命周期规则**，新增一条规则。

设置 `db_backups/` 前缀下的对象在 **30 天（或所需天数）后自动转为低频访问或自动过期删除**。
