## 1. 上传项目代码

### 1.1 使用 Git 克隆（推荐）

克隆项目仓库并进入项目目录：

```bash
cd /home/user
git clone https://github.com/yourusername/your-repo.git
cd your-repo
```

> [!warning] 警告
> **敏感信息**（数据库密码、JWT 密钥等）务必放在 `.env` 文件中，且**不要上传到 Git**。

### 1.2 使用 SCP 传输

在本地执行以下命令，用 `rsync` 传输构建产物：

```bash
# 本地执行（排除 node_modules）
rsync -avz --exclude='node_modules' ./dist/ user@your-server-ip:/home/user/my-node-app
```

## 2. 安装依赖与构建

### 2.1 安装依赖

安装生产依赖：

```bash
# 只安装生产依赖（跳过 devDependencies）
npm install --production

# 或更干净的安装方式（推荐）
npm ci --only=production
```

### 2.2 构建项目（TS）

编译 TypeScript 并检查编译产物：

```bash
# 编译 TypeScript
npm run build

# 检查编译产物
ls dist/
```

### 2.3 配置环境变量

创建 `.env` 文件：

```
PORT=3000
NODE_ENV=production
DATABASE_URL=your_database_url
JWT_SECRET=your_long_random_string
```

## 3. 运行项目

PM2 提供**崩溃自动重启、日志管理、内存监控、开机自启**功能。

用 PM2 启动项目：

```bash
pm2 start server.js --name "my-api"
```
