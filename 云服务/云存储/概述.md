| **维度**    | **块存储 (Block Storage)**     | **文件存储 (File Storage)** | **对象存储 (Object Storage)**    |
| --------- | --------------------------- | ----------------------- | ---------------------------- |
| **存储形态**  | 裸磁盘扇区/块（Block）              | 目录树状层级（Files/Dirs）      | 扁平桶结构（Bucket + Key）          |
| **操作单位**  | 固定大小数据块（如 4KB）              | 整个文件或文件段                | 完整对象（Object = 数据 + 元数据）      |
| **访问协议**  | iSCSI、FC、NVMe-oF、SAS        | NFS、CIFS/SMB、POSIX      | HTTP/HTTPS (RESTful API, S3) |
| **延迟/性能** | 极低延迟，高 IOPS                 | 毫秒级延迟，性能均衡              | 较高首包延迟，超高吞吐带宽                |
| **共享访问**  | 通常单节点独占挂载（需集群文件系统支持多挂载）     | 原生支持多机并发共享读写            | 原生支持海量客户端跨互联网并发读写            |
| **典型产品**  | AWS EBS、阿里云 ESSD、本地 SSD/HDD | AWS EFS、NAS、CephFS      | AWS S3、阿里云 OSS、MinIO         |
